# tugas-pemdas-sms1

Kumpulan tugas mata kuliah **Pemrograman Dasar (Pemdas)** Semester 1.

## 📚 Deskripsi

Repository ini berisi kumpulan tugas, latihan, dan project kecil yang dikerjakan selama mata kuliah Pemrograman Dasar di semester 1. Tujuan repository ini adalah sebagai dokumentasi pembelajaran sekaligus referensi bagi yang ingin belajar dasar-dasar pemrograman.

## 🧠 Materi yang Dipelajari

- Pengenalan algoritma & flowchart
- Tipe data, variabel, dan operator
- Input/Output
- Percabangan (if, else, switch)
- Perulangan (for, while, do-while)
- Array & String
- Function / Prosedur
- Struktur data dasar
- File handling (opsional)

## 🛠️ Bahasa & Tools

- Bahasa: **C / C++ / Python / Java** *(sesuaikan dengan yang dipakai)*
- Editor: VS Code / Dev-C++ / Code::Blocks / lainnya

## 🚀 Cara Menjalankan

1. Clone repository:

        git clone https://github.com/username/tugas-pemdas-sms1.git

2. Masuk ke folder tugas yang diinginkan:

        cd tugas-pemdas-sms1/pertemuan-01

3. Compile & jalankan (contoh untuk C++):

        g++ main.cpp -o main
        ./main
